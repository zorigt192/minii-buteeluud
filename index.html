Код бичих (kod bichih)

Програмчлалын үндэс, алгоритм, JavaScript болон тоглоомын хөдөлгүүрийн логик бичих.

🎨

Зураг дизайн (zurag dizain)

Тоглоомын дүрүүд, орчин, UI интерфэйс болон визуаль арт бүтээх чадвар.

🤝

Багаар ажиллах (bagaar ajillah)

Бусад дизайнерууд, хөгжүүлэгчидтэй хамтран ажиллаж, төслийг амжилттай дуусгах.
